1. 数据去向总览

数据类别处理方式
扩展设置、填充规则、表单模板保存在本机 chrome.storage.local，从不外发
数据池（你导入的 Excel 档案，可能含姓名/手机号/身份证号）保存在本机 chrome.storage.local，从不外发
随机生成的测试数据（姓名、身份证号、银行卡号等）在你的浏览器内即时生成，用完即弃，不落盘也不外发
网页表单内容仅写入你当前主动操作的那个页面，不读取其他页面内容、不回传
浏览历史、Cookie、账号密码完全不访问

All categories above are handled on-device only. Nothing is transmitted to LazyForm servers or any third party.

2. 本机存储的数据

LazyForm 只使用浏览器自带的本地存储 chrome.storage.local（以及可选的同步区）保存以下内容，它们始终位于你的设备上：

  • 你在设置页调整的生成规则与填充行为；
  • 你保存的表单模板（字段类型、勾选状态、固定值）；
  • 你导入的数据池档案；
  • 上一次版本检查的结果缓存（用于节流，避免频繁请求）。

卸载扩展时，浏览器会连同这些本地数据一并清除。

3. 唯一的外网请求：版本检查

LazyForm 只有一个对外网络访问，且默认是每天一次（可在设置页关闭）：

  • 请求地址：https://lazyform.qingtiangou.cn/version.json——这是我们自己的静态文件；
  • 用途：读取最新版本号、包大小与更新说明，用于在你的设置页显示「有新版本」提醒；
  • 请求体：不带任何本地数据，不携带标识、不含模板、不含数据池、不含你可能填过的任何内容；
  • 你可以在设置页 → 版本与更新里把「每天自动检查一次新版本」关掉，此后扩展完全离线运行。

The only outbound request is a daily GET to our own static version manifest. It sends no local data and can be disabled in Settings.

4. 明确不会做的事

  • 不使用任何第三方统计、埋点或分析 SDK，没有崩溃上报；
  • 没有账号体系，不需要注册或登录；
  • 不投放广告，也不内嵌联盟链接；
  • 不向第三方出售、出租或共享任何数据；
  • 不读取浏览历史、Cookie、密码；
  • 不在后台执行任何未经你主动触发的填充动作；
  • 不从远程加载或执行代码——全部逻辑都在扩展包内，随包分发。

No analytics, no accounts, no ads, no third-party sharing, no history/cookie/password access, no remote code execution.

5. 权限用途逐条说明

LazyForm 申请的权限及其用途如下，每一项都只用于实现「生成测试数据并填充表单」这一件事：

权限为什么必须用它
storage保存规则、模板、数据池与版本检查结果到本机
contextMenus提供右键菜单入口（在输入框右键生成数据、在页面右键打开工具）
scripting在你需要时把填充脚本注入当前标签页——表单可能在任意网站，因此无法限定到某个域名
alarms定时触发每天一次的版本检查
http://*/*
https://*/*		被测系统可能在任意测试环境（含内网 IP、非标准端口），必须对http/https 站点可用才能识别与填充表单；仅在你主动触发时作用于该页面

已移除的能力：自 v2.0.0 起，LazyForm 不再申请 file:///*，也不再生成任何证件图片； 同时移除了冗余的 activeTab 权限——在已持有 http/https 全站主机权限的前提下，该权限不带来任何额外能力。

6. Limited Use 声明

LazyForm 遵守 Chrome Web Store 的《User Data Policy》及其 Limited Use 要求：

  • 数据收集与用途严格限于「生成测试数据并填充网页表单」这一单一用途；
  • 数据不会用于与该用途无关的目的，也不会用于判断信用资质或放款评估；
  • 数据不会出售给第三方，也不会转移到与单一用途无关的第三方。

LazyForm complies with the Chrome Web Store User Data Policy, including Limited Use requirements: data is used solely for its single stated purpose, never sold, and never transferred for unrelated purposes or creditworthiness determination.

7. 你对自己数据的控制

  • 导出 / 导入：设置页 → 数据管理，可把配置导出为 JSON 备份；
  • 恢复默认：设置页 → 数据管理 → 恢复默认，清空规则、模板与数据池；
  • 关闭联网：设置页 → 版本与更新 → 关闭自动检查；
  • 彻底删除：在 chrome://extensions 移除扩展，所有本地数据随之清除。

数据池中的号码多用于测试场景，如其中包含真实个人信息，请按你所在组织的规范妥善保管。

8. 儿童与敏感数据

LazyForm 是面向开发者与测试人员的本地工具，不面向 13 岁以下儿童，也不会有意收集任何人的个人信息。生成的数据均为随机虚构值，号码虽通过校验位算法（GB 11643 / Luhn），但不对应任何真实自然人，不具备任何证件效力，请勿用于伪造材料或注册真实账号。

若本政策发生实质性变更，我们会更新页面顶部的「最近更新」日期，并在扩展的设置页与官网同步说明。继续使用即视为接受更新后的政策。
